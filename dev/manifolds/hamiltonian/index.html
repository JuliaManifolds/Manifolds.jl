Hamiltonian matrices

Manifolds.Hamiltonian — Type
Hamiltonian{T,S<:AbstractMatrix{<:T}} <: AbstractMatrix{T}

A type to store a Hamiltonian matrix, that is a square matrix for which $A^+ = -A$ where

\[A^+ = J_{2n}^{\mathrm{T}}A^{\mathrm{T}}J_{2n}, \qquad J_{2n} = \begin{pmatrix} 0 & I_n\\-I_n & 0 \end{pmatrix},\]

and $I_n$ denotes the $n×n$ identity matrix.

source
Manifolds.HamiltonianMatrices — Type
HamiltonianMatrices{𝔽, T} <: AbstractDecoratorManifold{𝔽}

The AbstractManifold consisting of Hamiltonian matrices of size $2n×2n$, i.e. the set

\[\mathfrak{sp}(2n,𝔽) = \bigl\{p ∈ 𝔽^{2n×2n}\ \big|\ p^+ = -p \bigr\},\]

where $⋅^{+}$ denotes the symplectic_inverse, and $𝔽 ∈ \{ ℝ, ℂ\}$.

Though it is slightly redundant, usually the matrices are stored as $2n×2n$ arrays.

The symbol $\mathfrak{sp}$ refers to the main usage within Manifolds.jl that is the Lie algebra to the SymplecticMatrices interpreted as a Lie group with the matrix multiplication as group operation.

Generate a random Hamiltonian matrix. Since these are a submanifold of $ℝ^{2n×2n}$, the same method applies for points and tangent vectors. This can also be done in-place of pX.

The construction is based on generating one normally-distributed $n×n$ matrix $A$ and two symmetric $n×n$ matrices $B, C$ which are then stacked:

\[p = \begin{pmatrix} A & B\\ C & -A^{\mathrm{T}} \end{pmatrix}\]

Return the dimension of the HamiltonianMatrices M over the number system 𝔽, that is

\[\dim \mathfrak{sp}(2n,𝔽) = (2n+1)n \dim_ℝ 𝔽,\]

where $\dim_ℝ 𝔽$ is the real_dimension of $𝔽$. For $𝔽 = ℝ$ this is the dimension of the SymplecticMatrices $\mathrm{Sp}(2n,ℝ)$, whose Lie algebra this is.

ManifoldsBase.project — Method
project(::HamiltonianMatrices, p)
project!(::HamiltonianMatrices, q, p)

Project a matrix $p ∈ 𝔽^{2n×2n}$ onto the HamiltonianMatrices $\mathfrak{sp}(2n,𝔽)$ relative to the Euclidean metric of the embedding $𝔽^{2n×2n}$, that is

\[ \operatorname{proj}_{\mathfrak{sp}(2n,𝔽)}(p) = \frac{1}{2}\bigl( p - p^{+} \bigr),\]

where $p^+$ denotes the symplectic_inverse of $p$. For $𝔽 = ℝ$ this is Proposition 2 in [GSAS21a] at the identity, whose tangent space is $\mathfrak{sp}(2n,ℝ)$ by Corollary 3.46 in [Hal15]. For $𝔽 = ℂ$ the real and the imaginary part are projected separately, see Proposition 3.38 in [Hal15].
