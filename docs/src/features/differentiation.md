# Differentiation

Documentation for `Manifolds.jl`'s methods and types for finite differences and automatic differentiation.

## Differentiation backends

The Riemannian differentiation backends, which compute Riemannian differentials and gradients with such an automatic differentiation backend, are provided and documented by [`ManifoldDiff.jl`](https://juliamanifolds.github.io/ManifoldDiff.jl/stable/).
